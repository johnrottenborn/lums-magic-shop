# Lum's Magic Shop

A whimsical storybook adventure starring Lum and her apprentice Cosmic. Play it at https://lums-magic-shop.vercel.app.

- `npm run build` builds the game into `dist/`.
- `npm run serve` plays it locally at http://localhost:8765.
- `npm test` plays through key moments on phone and desktop screens and saves screenshots.

Pushing to `main` deploys automatically. See `CLAUDE.md` for how the code is organised and the game's standing rules.
